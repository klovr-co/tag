# X launch copy — v0.1.0-alpha

## Primary post

Tag v0.1.0-alpha is live: a self-hosted way to bring Codex into Slack with
memory from sources you approve through MFS.

One guided installer. Slack-first. macOS + Linux. Apache-2.0.

It is an alpha for trusted sandboxes—not a production security boundary.

https://github.com/klovr-co/tag
