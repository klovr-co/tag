# Tag v0.1.0-alpha

Tag brings Codex into Slack as a shared, self-hosted teammate with context from
sources you explicitly index through MFS.

This first alpha supports Slack + Codex CLI + local MFS on macOS and Linux. It
includes a guided installer, a Slack app manifest, a small operational CLI,
scope-checked memory helpers, and automated release checks.

## Install

```bash
git clone https://github.com/klovr-co/tag.git
cd tag
./install.sh
./tag start
```

Follow the installer to create and authorize the Slack app. Start in a private
sandbox channel on a non-production host.

## Important limitations

- Tag converts chat messages into instructions for a local coding agent.
- It inherits the local account's files, credentials, tools, and permissions.
- It is not a hardened sandbox or production security boundary.
- Slack OAuth and workspace approval remain manual administrator actions.
- Claude Code and Zulip are included as experimental, not launch-qualified,
  paths in this release.

Read [SECURITY.md](../../SECURITY.md), the [release contract](../../RELEASE.md),
and [troubleshooting guide](../troubleshooting.md) before use.
